# SubTracker - учебный проект

Android-приложение на Kotlin для учёта подписок и регулярных платежей.
Учебный проект по университетскому курсу Android-разработки (не диплом).

## Стек
- Kotlin, Jetpack Compose (шаблон Empty Activity)
- minSdk 26
- Gradle Kotlin DSL
- package: ru.mihendy.subtracker

## Идея приложения
- Список подписок: название, сумма, валюта, период, дата следующего списания
- Экран создания/редактирования подписки, экран настроек
- Сеть: курсы валют с API ЦБ (https://www.cbr-xml-daily.ru/daily_json.js),
  пересчёт всех сумм в рубли
- Фон: WorkManager - уведомление «завтра спишется X», обновление курсов
- Хранение: сначала JSON-файл в filesDir, позже Room; настройки - DataStore

## Правила кода
- Модели - data class с val, изменения только через copy()
- Никаких `!!`
- Не добавлять библиотеки сверх необходимого для текущего задания
- Код и KDoc-комментарии — понятные, на защите их надо объяснять
- Комментарии в коде на русском
- После изменений запускать ./gradlew test и добиваться зелёных тестов
